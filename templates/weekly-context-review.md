## Worked distinction

On Wednesday, a user wrote, “This team never takes my ideas seriously.” The visible project note now says, “The team rejects the user's ideas.” The chat proves what the user said; it does not establish the team's general behavior. A Friday review can propose replacing the note with a dated report of that meeting, retaining the source and marking the broader interpretation unresolved. It should also preserve a documented missed deadline or substantive objection rather than remove it because the user disliked hearing it.
