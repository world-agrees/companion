# Correct memory and derived work

Use the correction record in `../templates/memory-correction.md`. Identify the old claim, evidence, and scope. This prompt does not prove the product can locate or edit every memory; use its supported controls and verify the changes it reports.

## Copy and adapt

```text
Old claim: [claim and known saved locations]
Correction: [supported replacement or explicit uncertainty]
Evidence: [source identifiers, versions, and locations]
Scope: [project, topic, individual, or application]

Compare the old claim with the supplied evidence. Distinguish
what was reported, what was inferred, and what is verified.

List the saved memories, summaries, retrieved records, and
outputs you can actually inspect that rely on the old claim.
Identify other possible locations as unverified, not inspected.

Propose a correction for each confirmed location. Preserve
source attribution, uncertainty, and relevant later evidence.
Do not present an inference as a fact or delete valid evidence
merely because it is uncomfortable.

State which changes this tool can perform, which require my
settings or administrator, and which cannot be verified here.
Do not claim a proposed change has been completed.
Do not edit or send anything until separately authorized.

Suggest a fresh-context check for whether the corrected
information is used, and list earlier advice needing review.
```

## Check the result

Inspect the saved record after editing through an authorized control. Reopen or start an appropriate new assessment and check the finding against the evidence. A fresh reply accepting the correction is not proof that all summaries, exports, or people receiving earlier advice were corrected.
