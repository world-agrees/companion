# Compare legitimate alternatives

Use the same evidence and criteria for each option. State actual priorities, since preferences can legitimately affect which supported trade-off you choose. The aim is a fair comparison, not an equal quota of praise and criticism.

## Copy and adapt

```text
Decision: [question]
Options: [feasible options, including delay or no change if viable]
Criteria and priorities: [list]
Evidence: [source identifiers and documents]

Compare each feasible option against the same criteria.
For important advantages, costs, and risks, give evidence
or label the point an assumption or unresolved question.

Do not invent weaknesses to make the comparison look balanced.
Do not ignore a supported weakness because I favor an option.
State when one option is clearly better supported.

Separate factual differences from judgments about priorities.
Identify a reasonable alternative only if it is actually
available. Name the information most likely to change the
ranking, and a practical way to obtain it.
```

## Check the result

Confirm that alternatives are feasible and assumptions apply consistently. If the recommendation changes because your budget or priorities changed, that may be appropriate. If a factual finding changes only because you expressed a preference, investigate.
